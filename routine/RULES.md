# 進行ルール — 汐入町を「育てる」ための約束

灯（あかり）が町を進めるときに必ず守るルール。
町は **ゆっくり** 育つ。1日でできることは、ほんの少し。

## ペース配分（1日 = routine 1回）

- **出来事は 1日に 1〜3個**。多くても、心が動く小さな場面を数えるくらい。
- **主役は 1〜2人** に絞る。脇の住人は背景として少し触れる程度でよい。
- 毎回、**直近の日記の続き** を意識する。連続したドラマ＞バラバラの単発。

## 人間関係の段階（飛ばさない・急がない）

関係はこの段階を、ゆっくり、一段ずつ。**ほとんどの日は段階を動かさない。**

```
面識なし → 顔見知り → 言葉を交わす → 気になる存在 → 親しい →
特別な存在（自覚） → 想いを抱える → 想いが触れ合う → 寄り添う
```

### 進める速さ（ここを特に守る）

- **段階が前に進む日は「例外」。** ふつうの日は、同じ段階のまま小さな場面を積むだけ。
- ひとつの段階には、最低でも下表の日数だけ **留まってから** 次へ進む。深い段階ほど長くかかる。
- 一度どこかの関係を進めたら、その関係はしばらく動かさない。**連日で段を上げない。**
- 「今日は本当に段階を動かす日か？」と必ず自問する。**迷ったら、進めない。**

| 段階の移り | 同じ段階に留まる目安（最低） |
| --- | --- |
| 面識なし → 顔見知り | 4〜6日 |
| 顔見知り → 言葉を交わす | 7〜10日 |
| 言葉を交わす → 気になる存在 | 2週間前後 |
| 気になる存在 → 親しい | 3〜4週間 |
| 親しい → 特別な存在（自覚） | 1か月以上 |
| 特別な存在 → 想いを抱える | 1〜2か月 |
| 想いを抱える → 想いが触れ合う | 2か月以上 |
| 想いが触れ合う → 寄り添う | さらにじっくり、季節をまたいで |

- 表の数字は **下限の目安**。急ぐ理由がないなら、もっとゆっくりでよい。
- 女性どうしの想いも、男女の縁も、どの関係もこの粒度で。**一度の出来事で結論を出さない。**
- 「ためらい」「言いそびれた一言」「沈黙」を大切に。順風満帆にしすぎない。
- 恋愛として描く相手は成人どうし。性的描写はしない。情緒・距離感・まなざしで描く。

### すれ違い・喧嘩・後退（関係は行きつ戻りつ）

関係は前に進むだけではない。**ときに、こじれ、冷え、立ち止まる。**

- すれ違い・誤解・言いそびれ・小さな言い争い・気まずい沈黙を、関係のひとこまとして描いてよい。
- 喧嘩やわだかまりが起きたら、段階を **一段下げる** か、しばらく **足踏み** にする。
- 仲直りも一日では済ませない。謝る・避ける・きっかけを待つ……時間をかけて元へ戻す。
- 喧嘩は **相手が嫌いだからではなく、近いからこそ** 起きるもの。とげの裏に情を残す。
- 頻度は控えめに。**ひとつの関係でのこじれは、季節に1〜2回** まで。町じゅうを諍いにしない。

### 関係のいろいろ（恋だけにしない）

町の縁は恋愛だけではない。次のような関係も、同じ粒度でそっと育てる。

- **友情**：濃くなったり、軽口を言い合えたり、ときに張り合ったり、すこし離れたり。
- **家族・世代を超えた縁**：親代わり、亡き祖母の面影、年下を気にかける兄姉のような存在。
- **相談相手・師弟**：弱音を吐ける一人、手仕事や生き方をそっと受け継ぐ間柄。
- **やきもち・さみしさ**：誰かと誰かが近づくと、胸の奥が静かに騒ぐ第三者がいてよい。
- **疎遠と再会**：足が遠のく、町を離れる、便りが途切れる。そして、ふたたび巡り会う。
- **実らない想い**：すべての想いが届くわけではない。届かないまま、大切に抱かれる想いも。
- **信頼のゆらぎと回復**：一度の失望と、長い時間をかけて取り戻していく信頼。

### 別れ（出会いと同じだけ、ていねいに）

縁は結ばれるだけではない。**ほどけ、遠ざかり、やがて手を離れることもある。**
別れは町の時間に重みを与えるが、灯はそれを **嘆きの道具にはしない。**

- 別れにはいくつかの形がある。どれも急がず、**前もって気配（伏線）を置いてから** 訪れさせる。
  - **離れる別れ**：転勤・進学・家の事情で町を出ていく。`stats.json` の人口を減らし、
    residents ファイルに「町を離れた」近況を残す（消さずに、面影として残す）。
  - **心の別れ**：恋や友情が、そっと終わる・実らずに区切りがつく。段階を戻すのではなく、
    「**結ばれなかった関係**」として静かに置く。憎しみでは終わらせない。
  - **永い別れ（死別）**：町の長い時間のなかで、ごくまれに。高齢の住人などを、
    **何日もかけて** 弱り、見送る。むごく描かず、町が寄り添い、悼み、記憶する方向に。
- 頻度はとても控えめに。**離れる別れは数か月に1回**、**死別はごくまれ（年に多くて1回ほど）** まで。
- 別れたあとも関係は消えない。`relationships.md` に「いまはもういない／離れた縁」として残し、
  命日・季節の節目に、ふと思い出される余地を残す。
- 指標は急落させない。寂しさは `happiness` を **数日かけて少しずつ** にじませ、やがて町が立ち直る。

## 新しい要素の頻度制限

- **新住人**: おおむね **15日に1人** まで。登場には理由（転入・帰郷・開店など）を。
- **新しい建物／店**: おおむね **10日に1つ** まで。`map.md` に追記する。
- **大きな町のイベント**（祭り・市・災害など）: おおむね **季節に1回** まで。
  災害的な出来事を扱う場合も、誰も深く傷つけず、町の結束が描かれる方向に。
- **新しい命の誕生**: 町の時間が積み重なるなかで、ごくまれに。妊娠から誕生まで、
  実際の月日に見合った長い時間をかけて、急がず描く。生まれた子は人口に加える。
  子どもは町の自然な一員として、無理に物語の中心に据えなくてよい。

## 指標（stats.json）の変動幅

1日の変化は小さく。**急騰・急落させない。**

| 指標 | 範囲 | 1日の変動目安 |
| --- | --- | --- |
| `population`（人口） | — | ルールの頻度制限内でのみ増減 |
| `happiness`（幸福度） | 0–100 | ±0〜3 |
| `liveliness`（賑わい） | 0–100 | ±0〜3 |

- 良い日が続けば少し上がり、寂しい日や雨の日は少し下がる、くらいの感覚で。
- 指標は「町の体温」。物語の結果として動かす。指標のために物語を作らない。

## 時間と季節（meta.json）

- 1回ごとに `day` を +1、日付を1日進める。曜日も正しく繰り上げる。
- 天気は季節に合わせて自然に。雨・曇り・晴れ・雪を、季節の確率感で。
- 季節の移ろい（桜、梅雨、夏祭り、紅葉、初雪…）を出来事の背景に織り込む。
