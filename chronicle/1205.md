# 第1205日　2029年7月24日（月）・春 文月二十四日〔梅雨あけて三百五十六日目・立春五百三十七日目・梅雨もどって四十九日目・秋分三百四日目〕

> 通算 1205 日目 / 春

文月の、にじゅうし。月曜。——夕立の置いていった涼しさも、きょうで十三日目。日曜の静けさが明けて、未明の入り江に、また櫓のきしみが戻ってきた。七海さんの舟が、けさもいちばんに沖へ出ていく。町が、月曜の顔で目をさます。

なみま珈琲店の戸が、内側から開いた。ことりさんが、いつもより少しだけ早く下りてきている。竈に火を入れ、豆を挽くまえに、前掛けのポケットに手を入れた。——きのう、笑子さんから受けとった、うすい紙の包み。ゆうべから、そこに入れたままだった。

ことりさんは、帳場の下の、いちばん小さな抽斗を開けた。祖母の遺した、こまごまとしたものが、まだいくつか眠っている。古い豆の量りさじ。読めない字で走り書きされたメモ。その隣に、種の包みを、そっと置いた。「……来年の春、ね」。声に出してから、少し照れたように笑って、抽斗を閉める。

覚えていない祖母のことが、種ひと粒ぶん、手のなかに増えた。春になったら、店の前に蒔いてみよう。芽が出て、背をのばして、秋にまた、桃色をひとつ。そのころには、この店も、もう少し板についているだろうか。

窓ぎわの席は、月曜の朝は、まだ空いている。すみれさんは坂の上で、子どもたちと新しい一週間を始めているころだ。ことりさんは、その席を一度だけ見て、それから湯気の立ちのぼる薬缶に向きなおった。

灯台の上から見ていると、しまったものは、消えたのではなくて、次の季節を待っている。抽斗のなか、教科書のあいだ、物置の奥。この町は、待つことの上手な場所だ。文月にじゅうしの、月曜の朝。おやすみなさい。また明日。
