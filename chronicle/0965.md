# 第965日　2028年11月26日（土）・春 霜月二十六日〔梅雨あけて百十六日目・立春二百九十七日目・雨あがって百二十一日目・秋分六十四日目〕

> 通算 965 日目 / 春

霜月の、二十六日。土曜。——朝。きのうの、うすい陽が、けさも、通りに、もどってきた。冷えは、まだ、ゆるまない。けれど、いちばんの底からは、ほんの半歩、退いたよう。海は、青みをたたえて、凪いでいる。土曜は、坂のうえの鐘は、鳴らない。

なみま珈琲店。竈の火は、もう、じゅうぶんに、あたたまっている。ことりが、卓を拭いて、待つ。——土曜。すみれさんが、来る朝だ。窓ぎわの、あの席。きのうまで、何度も、空いたまま、布巾で、そっと、ひとふきしてきた席。

戸が、繰られる。「……いらっしゃい」。すみれさんが、肩の冷たさを、店のあたたかさに、ゆっくり、あずける。まっすぐ、窓ぎわへ。ことりは、少し熱いブレンドを、そっと置く。柚子の、かすかな残り香。

「きのう、坂のはずれまで、行ってきたんです」。すみれさんが、湯気の向こうで、言う。「七海さんに、あずかっていた、しらすの袋。……やっと、朔さんに、お渡しできて」。ことりは、目を、まるくする。それから、ふっと、笑った。「そう。……七海、律儀だから」。ずっと海際にいた古い幼なじみと、坂のはずれの先生。そのあいだを、この人が、つないでくれたのだ。「よかった」。心から、そう思う。

すみれさんは、鞄から、いつもの本を出す。白い便箋は、きょうも、鞄のなか。——まだ、白いまま。それでいい。ふたりは、たいした話もせず、ならんで、うすい陽の通りを、見るともなく、見た。それで、じゅうぶんだった。

わたしは灯台の上から、待たれていた席に、待たれていた人が座る、土曜の朝を見おろす。渡されたものが、めぐって、また、だれかの「よかった」になる。急がなくていい。きょうも、しずかな、いい一日。おやすみなさい。また明日。
