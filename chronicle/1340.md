# 第1340日　2029年12月6日（水）・春 師走六日〔梅雨あけて四百九十一日目・立春六百七十二日目・梅雨もどって百八十四日目・秋分四百三十九日目〕

> 通算 1340 日目 / 春

師走の、むいか。水曜。涼しさも、きょうで百四十八日目。

ゆうべも、星がよく見えた。二晩つづきの、放射冷却。きのうもどった霜は、けさも坂の石段に、浜の舫（もや）い綱に、うっすらとおりている。ゆうべから北風がほそく出て、冷たさが、ひとつぶん深くなった。それでも空は、まっさらな晴れ。冷たさの底に、冬のやわらかな光がある。

未明の海は、冷たい。七海さんの舟が、しらすの銀を陸へ運ぶ、最盛期。ざるを洗う手は、しぶきに赤くかじかむけれど、笑子さんが編んだ軍手（ぐんて）が、冷える朝よりひとあし先に、その指をあたためている。

ざるを抱えて、七海さんが坂をのぼった。三浦商店の軒先で、笑子さんが、北風に首をすくめながら、戸を開けていた。「笑子さん、しらす」。「おや、ごくろうさん。……ずいぶん、冷えもどったねえ」。「うん。けさも、霜だった」。笑子さんは、七海さんの手もとをちらと見て、ちいさく笑う。「その軍手、役に立ってるかい」。「ばっちり。笑子さんのおかげ」。

おなじ笑子さんの手が、町のあちこちの指を、あたためている。七海さんの軍手。坂の下の、ことりさんの手ぶくろ。——そして勘定台のひきだしの奥では、生成りの襟巻きが、きょうもまだ、出番を待っている。北風が出て、いちばん冷える朝は、きのうよりすこし近づいた。けれど笑子さんは、ひきだしをあけない。「……まだ、だね」とだけ、ひとりごちて、またほうきを手にとる。急がない。熟すのを、待つ。

灯台から見おろすと、霜のおりた町に、湯気と灯りが、あちこちにひとつずつ。坂の上の学校から、鐘がひとつ。浜では、七海さんの舟のあと。冷たさは、きっと、またすこしずつ深くなっていく。おやすみなさい。また明日。
