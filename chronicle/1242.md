# 第1242日　2029年8月30日（水）・春 葉月三十日〔梅雨あけて三百九十三日目・立春五百七十四日目・梅雨もどって八十六日目・秋分三百四十一日目〕

> 通算 1242 日目 / 春

葉月の、みそか。水曜。——涼しさも、きょうで五十日目になった。ゆうべ低く垂れていた雲が、夜のうちにほどけて、朝の海は、ふちのほうまで澄んでいる。日ざしはまだ淡いけれど、きのうよりは、まっすぐだ。

七海さんの舟は、けさもいちばんに沖へ出て、いちばんに帰ってきた。しらすを揚げ、網を干して、ざるを洗う。潮に浸けどおしの指さきが、このごろ、ひび割れて痛む。舟の物入れの、あの小さな缶を振ってみると——もう、かたかたと軽い。「……そろそろ、切らすな」。

昼まえ、七海さんは浜から汐見通りへ上がってきた。三浦商店の戸は、きょうも開いている。季節の棚の、いちばん手前。ならんだ小箱に、七海さんの目がとまった。あかぎれと、ひびの、塗り薬。「あ、これこれ」。手にとって、迷わずひと箱。「笑子さん、これ、もらうね」。

笑子さんは、勘定台で受けとって、そろばんの珠をひとつ、ふたつ。「日に焼けた顔して、指だけはあかぎれかい」。「しょうがないよ、海だもん」。七海さんが、からっと笑う。——笑子さんは、その薬をゆうべ棚の手前に出したのが、ほかでもない、この子の手を思ってのことだとは、言わない。ただ、釣り銭を、あたたかい手のひらに落とすように渡す。

勘定台の隅には、まだ、あの軍手のひと山。笑子さんの指が、いちど、そちらへ動きかけて——止まる。「……まだ、その朝じゃない」。冬の、ほんとうに冷える朝が来たら。そのとき、いちばんいい顔で渡すのだ。きょうは、薬ひと箱で、じゅうぶん。

七海さんは、箱を胸ポケットにしまって、また坂を下りていった。わたしは灯台から、その背中と、棚のひとつ空いたところを、いちどに見おろしていた。案じる手は、渡さなくても、ちゃんと届くことがある。よろず屋の棚の、いちばん手前から。おやすみなさい。また明日。
