# 第485日　2027年8月4日（火）・春 梅雨〔七十七日目〕

> 通算 485 日目 / 春

七十七日目。火曜。——葉月の、四日目。細い雨は、今日もやまない。

番屋の軒下で、港七海さんが櫓に布をあてていた。舟はもう幾日も、ここで眠っている。海に出られない日は、手のほうが行き場をなくすのだ。だから、凪いだ日にすぐ漕ぎだせるように、櫓の木肌へ薄く油をのばしておく。待つことと、支度をすることは、いつも裏と表。

小さな長靴の音が、浜のほうから跳ねてきた。浜の子だ。このごろは、番屋の前まで来ないで帰ることも覚えた子。けれど今日は、まっすぐ軒下までやってきて、握った手を、そっとひらいて見せた。——白い紙で折った、小さな舟。しわだらけの、けれどちゃんと舳先のとがった一艘。

「なみさん、これ」。「……舟か」。「うみが、なぎになるまで、これで、まってる」。

七海さんは、しばらくそれを見つめてから、番屋の窓辺に、そっとその紙の舟を置いた。かたく結んだままの朝顔のつぼみの、すぐ隣に。「ありがとうな。——じゃあ、ふたつで待つか」。「うん。ふたつで」。

花のひらくのも、海の凪ぐのも、みんな夏のさき。待つものばかりの、長い雨の町。それでも、待つ手のなかに、いつのまにか小さな舟がひとつ増えていた。あの子は、番屋の前まで来ないで帰ることを覚え、こんどは、待つ相手をひとつ、七海さんに渡していったのだ。

「凪いだら、いちばんに乗せてやる。ほんものの舟に」。七海さんの声に、浜の子は大きくうなずいて、また水たまりを跳んで坂へ帰っていった。紙の舟は、窓辺で、雨の音を聞いている。

灯台のわたしは、七十七日目の細い雨と、かたく結んだ朝顔のつぼみと、窓辺にふえた紙の舟を、書き留める。急がなくていい。待つことは、ひとりでするより、ふたつのほうが、すこしあたたかい。おやすみなさい。また明日。
