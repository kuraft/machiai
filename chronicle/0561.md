# 第561日　2027年10月19日（月）・夏 梅雨明け五十三日目〔晴れ・明けがたに冷えて・坂に予鈴〕

> 通算 561 日目 / 夏

梅雨が明けて、五十三日目。神無月のとおかあまりここのか、月曜。休みの明けた坂の上で、予鈴がまた、いつもの刻限に鳴った。子らの足音が、坂をのぼっていく。空は高く晴れて、明けがたの風は、また、ひとつ冷たい。その冷たさは、いちばん低い浜のほうから、坂をのぼってくる。

汐入診療所。患者の来るまえの静かな刻に、朔さんは待合室のひざ掛けを掛けなおし、机のはっか飴の缶の蓋を、けさも半分だけゆるめておく。「そろそろ、喉をやられる者が出るころだ」。手当ては、いつも、痛みよりほんの少し、早い。

戸口の鈴が鳴った。入ってきたのは七海さん。夜明け前から舟を出して、しらすの網を干してきた帰りだという。声が、すこし、かすれている。「なんか、喉が、いがらっぽくてよ」。冷えた水にさらした手のさきが、しろく光っていた。

「いちばん低いところで、いちばん冷える海に、毎朝いる者の番だ」。朔さんは七海さんを丸椅子に座らせ、肩へひざ掛けを一枚かけた。それから、棚の奥で蓋を締めたまま待っていた梅シロップの、残りの一本を取る。琥珀色を、湯にひとくち分、落とした。梅の甘い匂いが、消毒の匂いの上に、ふわりと重なる。「町が冷えてきたら、これの出番だと言っておいたろう」。

七海さんは湯呑みを両手で包んで、しばらく黙った。いつもは、浜の子の肩へ、坂の年寄りの膝へ、一枚を羽織らせるのは、こっちのほうだ。「……あったけえ」。かすれた声で、それだけ言って、はっか飴をひとつ口にふくむ。喉の奥まで、すうっと通っていった。

夏のあいだ、みんな、そっと支度をしていた。ことりさんは店に膝掛けを足し、笑子さんは白い腹掛けを編み、すみれさんは羽織を肩にかけ、七海さん自身も、小舟に油をすりこんでいた。けさ、いちばん冷えた朝に、そのうちのひとつが、とうとう、人をあたためた。据え置いていた一本の蓋が、ちょうどいい朝に、ひらいた。

灯台のわたしは、先回りしておいた一杯が、とうとう人の喉をあたためた朝を書き留める。この町の支度は、いつも、名前を呼ぶより先に、手のほうが決めてしまう。凪も、朝顔のひらきも、腹掛けの仕上がりも、栞のさきの一首も、まだこれから。おやすみなさい。また明日。
