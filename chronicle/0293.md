# 第293日　2027年1月24日（土）・冬晴れ〔おだやか・凪三日目〕

> 通算 293 日目 / 冬

睦月二十四日、土曜。初雪から、十一日。凪は、まだ続いている。朝はおだやかに晴れて、低い日ざしが、乾いた坂をゆっくりあたためていく。海は、三日目の青。港では、七海さんの舟が、もう沖に出ている。漕げる朝は、漕いでおく人だ。

土曜は、すみれさんの、授業のない日。きのうの夕方、坂をのぼりながら「明日はちゃんと朝に行こう」と思った——そのとおりに、朝のうちに、硝子戸が鳴った。鞄のかわりに、文庫を一冊だけ抱えて、すみれさんが「いつもの窓際」に座る。ことりは、湯のみを伏せずに、あたたかいブレンドを、そっと運んだ。「……あたたかい」。それだけ。向かいには、座らない。カウンターの内と、窓際の外のまま。

「……ゆうべの、甘夏」と、すみれさんが、頁から目をあげた。「あれ、ぬるくなっても、ずっと、あまかったです」。ことりは、すこし笑って、「……よかった」とだけ言った。分けたものが、季節をまたいで返って、その甘さが、まだ、あの人のなかに残っている。それを聞けただけで、じゅうぶんだった。

平日より、すこし長い在席。すみれさんは、頁をひらいたまま、ときどき、硝子のむこうの青い遠い海を見る。「……いい、天気ですね」。「ええ。……風も、ないです」。ぽつり、ぽつり。あとは、しずかな時間。ふたりぶんの湯気が、おなじ光のなかに、まっすぐ立っていた。

灯りのとなりの文庫は、今日もひらかない。冬晴れの土曜だから。雨の歌は、雨の日に。あの人が、ここにいる、雨の日に——その日は、まだ、来ない。

蠟燭は、日暮れにまた、ひとつ。夜の長い季節を、毎晩ひとつずつ。

わたしは灯台から、窓際で本を読む人と、カウンターの内でそれを見ないふりで見ている人を見おろしていた。何も進まない。何も、急がない。ただ、おなじ光を、分け合う朝。それが、いちばん、あたたかい。また明日。
