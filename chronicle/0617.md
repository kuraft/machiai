# 第617日　2027年12月14日（月）・夏 梅雨明け百九日目〔雨あがって四日目・冬晴れ・凪やぶれて七日目・海の白い波なおひくく〕

> 通算 617 日目 / 夏

師走の、じゅうごにち。月曜。雨のあがって四日目、けさも空はどこまでも高い。坂の霜は朝日にとけて、水たまりはもう乾いた。海はまだ白いけれど、波のあたまは、きのうよりまた低い。凪がやぶれて、七日目。舟の出る朝は、日ごとに近づいてくる。

朝いちばん、なみま珈琲店の硝子戸を、ことりが開ける。夜のあいだ店にこもった冷えを、澄んだ外の朝へ逃がす。豆を挽く音、湯のわく音。木の床が、すこしずつあたたまっていく。椅子の背には、膝掛けが二枚、畳んでかけたまま。窓ぎわの雨の歌の文庫は、栞をはさんで、きょうも閉じている。晴れの日に、ひらく本ではない。

鈴が鳴って、すみれさんが入ってきた。授業のある月曜、鞄を肩に、いつもの窓際へ。「おはようございます」「おはよう。……いいお天気ですね」。ことりは、いつもより少しだけ熱いブレンドを出す。すみれさんは器を両手でくるんで、白い息をひとつ、窓の光へ逃がした。

「海、落ちついてきましたね」。窓の外、坂の下の海を見て、すみれさんが言う。ことりは頷いて、「七海が、そろそろだって。凪が戻れば、舟を出すって」。幼なじみの名を、そう口にする。凪待ちの浜のことは、この町のだれもが、すこしずつ知っている。

一杯を飲みほして、すみれさんは立ちあがった。「行ってきます」。戸口で、その言葉を、ことりはきょうも見送る。冬晴れの坂を、鞄がひとつ、のぼっていく。

灯台のわたしは、月曜の朝の湯気と、窓ぎわのひとことを書き留める。海が凪ぐのも、朝顔がひらくのも、まだ閉じたままの本のさきの一首も、みんな、その日を待っている。急がなくていい。師走の、じゅうごにち。おやすみなさい。また明日。
