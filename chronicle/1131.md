# 第1131日　2029年5月11日（木）・春 皐月十一日〔梅雨あけて二百八十二日目・立春四百六十三日目・雨あがって二百八十七日目・秋分二百三十日目〕

> 通算 1131 日目 / 春

皐月の、じゅういち。木曜。——朝。けさも、うすぐもり。きのうの、あの重い風が、まだ、坂のあいだに、居のこっている。空は、白い。日ざしは、雲のむこうで、ぼんやり、やわらかい。立夏の、むいか。

三浦商店。笑子さんが、店の奥から、古い木の箱を、ひとつ、引っぱりだしていた。ふたを、あける。中には、子どもの傘が、何本か。赤や、黄色や、水玉の、小さいの。去年の梅雨に、しまいこんだきり、ずっと、眠っていたものだ。「……そろそろ、だね」。埃を、はたきで、はらう。

一本ずつ、ひらいて、破れがないか、たしかめて、店先の、傘立てに、立てていく。よろず屋の軒が、ぱっと、いろどりを、まとう。まだ、雨は、降らない。けれど、坂の下の浜の子が、坂の上の子らが、いつ、駆けこんできても、いいように。「濡れて帰るのだけは、いけないよ」。だれにともなく、笑子さんは、つぶやく。

勘定台のわきには、春に売れのこった、花の種の紙袋が、まだ、ならんでいる。あのころ、ひと袋、ふた袋と、わけていった種は、いまごろ、坂の上の、どこかの庭で、芽を、のばしているだろうか。行く春の種と、来る梅雨の傘とが、店先で、しばらく、となりあう。笑子さんは、そのふたつを、目で、なでて、ふふ、と、笑った。

わたしは、灯台の上から、いろどりの増えた軒先を、見おろしていた。網を干す手、くすり草を待つ指、古い傘をあらためる手、そして、子どもの傘をならべる手。町じゅうが、めいめいの場所で、おなじ季節を、迎えるしたくを、している。まだ降らない。けれど、来る雨に、濡れる人が、ひとりも、いないように。きょうも、しずかで、あたたかい、いい一日。おやすみなさい。また明日。
