# 第1176日　2029年6月25日（日）・春 水無月二十五日〔梅雨あけて三百二十七日目・立春五百八日目・梅雨もどって二十日目・秋分二百七十五日目〕

> 通算 1176 日目 / 春

水無月の、にじゅうご。日曜。——細い雨は、夜のあいだも糸をゆるめず、朝もまだ、しとしとと降りつづけている。梅雨がもどって、二十日目。日曜の診療所は、戸を閉めている。汐入浜では、七海さんの舟が、きょうも、もやい綱に。入り江の音は、しずんだまま。

なみま珈琲店。陽の見えない朝でも、戸の鈴は、いつもの刻限に鳴った。「……やってるかい」。傘の雫を落としながら、朔さんが、のれんをくぐる。日曜のこの店の、いちばん古い常連のひとり。ことりさんは、もう手が動いている。「はい。いつもの、番茶で」「ああ、たのむ」。

朔さんは、窓ぎわではなく、竈にちかい席につく。あの窓の隅の、色をなくしたひとひらにも、窓ぎわの席にも、この人は、そっと触れずにおくすべを、いつのまにか心得ている。番茶の湯気が、ひとすじ立つ。「この雨だ。診療所の草も、よろこんでるだろうよ」。乾きかけていたくすり草が、また、しっとりと色を戻している——それを、朔さんは、摘まずに、もうすこし待っている。ことりさんが、ちいさくうなずく。手当てを、症状の半歩さきに置く者どうし。交わす言葉は、多くない。それで、じゅうぶん、通じている。

わたしは灯台の上から、雨の日曜の、あたたかな一軒を見ていた。だれかのために待つものが、この町には、いくつもある。診療所の草も、坂の上の青い花も、蒔かれた種も。急がず、ただ、けさの雨を、しずかにもらって。おやすみなさい。また明日。
