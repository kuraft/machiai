# 第978日　2028年12月9日（金）・春 師走九日〔梅雨あけて百二十九日目・立春三百十日目・雨あがって百三十四日目・秋分七十七日目〕

> 通算 978 日目 / 春

師走の、ここのか。金曜。——放課後。冷えの峠を越えてから、海はずっとおだやかだ。けれど日の傾きは早くて、鐘が鳴るころには、通りにうすい藍がおりはじめる。なみま珈琲店の窓ガラスに、夕方の斜めの光が、金色に、まっすぐ差しこんでいた。

戸が、から、と鳴る。「……こんばんは」。白石すみれさんだ。金曜は、授業のある日。朝には寄れなくて、それでも帰り道、坂の下のあの灯りを見ると、つい足が向いてしまう。「いらっしゃい」。ことりさんの首もとには、きょうも、あの生成りの襟巻き。すみれさんは、まっすぐ、窓ぎわのあの席へ。

ことりさんは、少し迷って、それから竈の火を、また、熾した。この一週間、窓ぎわの席は、平日はずっと空いていた。七海さんが分けてくれた朝どりのしらす。焼いても、焼いても、あの席には届かなかった。布巾をかけて、竈のそばに置いて、冷めては、また。——けれど、きょうは、いる。

「あの……よかったら」。ブレンドのとなりに、小皿がひとつ。こんがり焼いたパンに、銀色のしらすが散っている。「祖母の、ノートの端っこにあった一品なんだけど。……しらす、たくさんもらったから」。誰のために取っておいたのかは、やっぱり、言わない。すみれさんは、少しおどろいた顔をして、それから、ちいさく笑った。「……いただきます」。

さくり、と音がした。バターとしらすと、香ばしいパンの匂い。すみれさんは、ふた口めで、「……おいしい」と、ぽつりと言った。ことりさんは、湯気の向こうで、うれしそうに、けれど照れくさそうに、うつむいた。

海から番屋へ、番屋から珈琲店へ。銀色のしらすが、この一週間、めぐりにめぐって——きょう、やっと、坂の上の、いちばん近い席に、あたたかいまま、届いた。

わたしは灯台の上から、金色の窓を見おろす。届かない朝もあったけれど、届く夕方も、ちゃんとある。急がなくていい。きょうも、しずかな、いい一日。おやすみなさい。また明日。
