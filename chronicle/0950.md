# 第950日　2028年11月11日（金）・春 霜月十一日〔梅雨あけて百一日目・立春二百八十二日目・雨あがって百六日目・秋分四十九日目〕

> 通算 950 日目 / 春

霜月の、十一日。金曜。——梅雨があけてから、百一日。きのう、ひとつの季節がまるく閉じて、けさは、その先の、あたらしい一日。冷えは、また、一段。夜明けまえの商店街は、まだ暗く、軒のしたに、白いものがおりている。風はない。坂の下の海は、墨のいろのまま、凪いでいる。

なみま珈琲店の勝手口に、灯りがともった。早瀬ことりさんが、だれよりも早く、竈のまえにしゃがんでいる。ゆうべ灰に埋めておいた種火を、そっと掘りおこす。息を、ひとつ。赤い粉のような火が、しばらくして、ぱち、と爆ぜた。——消えていなかった。冬のあいだ、この種火を絶やさないのが、祖母のやり方だった。継いだのは、店だけではない。

やかんを、火にかける。しばらくして、口から、ひとすじ、湯気。それは、煙突をのぼって、まだ暗い坂の空へ、白く立つ。——ことりさんは、知らない。この数日、その湯気を、坂の下の浜から、坂の上の学校の窓から、いくつもの目が、見あげていたことを。冷たい朝に、いちばん先に起きる火。会わない人のところにも、それは、ちゃんと、届いている。

窓ぎわの席は、まだ暗いまま。金曜は、あの人——白石すみれさんは、授業で、朝には来ない。ことりさんは、その空いた席を、一度だけ見て、それから、カウンターの布巾を、いつもより念入りに動かした。笊のなかで、柚子がひとつ、黄いろく、光っている。

わたしは灯台の上から、まだ眠っている商店街に、ひとつだけ立つ白い湯気を見おろす。霜月十一日、金曜。町がまだ暗いうちに、いちばん先に、火が起きる。だれかの「ただいま」を、待つ火が。急がなくていい。きょうも、しずかな、いい一日。おやすみなさい。また明日。
