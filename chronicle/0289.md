# 第289日　2027年1月20日（火）・雨〔冬の雨〕

> 通算 289 日目 / 冬

睦月二十日、火曜。初雪から、七日。きのう、あんなに焦らした空が、夜明けまえに、とうとうほどけた。冷たい雨。雪ではなく、雨のほう。七海さんの読んだとおりだ。三日かけて近づいてきたものが、今朝、しずかに落ちてきた。

港では、七海さんが、舟を出さなかった。帆布をかけ直して、しばらく雨の浜をうろうろして——それから、手ぶらのまま、坂をのぼってきた。「なんにも持ってこられない朝は、調子くるうね」。梅雨のころと、おなじ台詞。ことりが、黒板の〈しょうがのはちみつ湯〉を、黙って差し出す。両手で包んで、湯気を顔に当てて、「生き返る」。いつもは七海さんがことりの世話を焼くのに、雨の朝は、いつも、逆になる。

窓際は、火曜で、空いている。すみれさんは、坂の上の学校。雨の日も、授業はある。ことりは、湯のみをひとつ、そっと伏せて置いた。来ない日の、ぶんまで。

そして——灯りのとなりの、あの一冊。雨の歌の文庫。今日は、雨だ。「雨の歌は、雨の日に」。その日が、とうとう来た。ことりの手が、背表紙にかかって……けれど、ひらかなかった。空は、もう、いい。足りないのは、天気じゃない。ひらくのは、あの人が、ここにいる日がいい。栞をはさんだまま、文庫は、また、次の雨を待つ。——ちがう。次の、あの人のいる雨を。

帰りぎわ、七海さんが傘も持たずに来たのを見て、ことりが、傘立ての赤い番傘を一本、握らせた。「濡れて帰るやつがあるか」。梅雨のとき、朔さんが七海さんにそうしたみたいに。「借りとく」。赤い番傘が、雨の坂を、くだっていく。次の雨の支度が、ひとつ、ほどけた。

硝子戸のそばの蠟燭は、雨の日暮れにも、また、ひとつ。夜の長い季節を、毎晩ひとつずつ。

わたしは灯台から、灰いろの海と、出されなかった舟と、ひらかれないまま灯りのそばで待つ一冊を見おろしていた。天気は、そろった。あとは、人だ。急がなくて、いい。雨は、きっと、また降る。そのとき、あの人が、ここにいてくれたら——文庫は、その日に、ひらく。また明日。
