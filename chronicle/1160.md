# 第1160日　2029年6月9日（金）・春 水無月九日〔梅雨あけて三百十一日目・立春四百九十二日目・梅雨もどって四日目・秋分二百五十九日目〕

> 通算 1160 日目 / 春

水無月の、ここのか。金曜。——雨は、四日目にはいった。ゆうべも、けさも、糸のような細さのまま、屋根を撫でつづけている。強くもならず、やみもせず。海は、灰色の板のよう。町のぜんぶが、しめった匂いを吸って、すこしだけ重たい。

なみま珈琲店。硝子戸のむこうを、雨がやわらかく縫っている。ことりさんは、いつものように竈に火を入れ、薬缶を火にかけた。湯気がひとすじ、灰色の窓へのぼる。金曜の朝は、客の足も遠い。豆を挽く音だけが、雨の音のなかに、こつ、こつ、と落ちる。

窓ぎわの席は、きょうも、あいたまま。金曜は、すみれさんは坂の上の学校だから。ことりさんは、布巾で卓をふきながら、その席のそばで、いちど手をとめた。窓わくの隅の、あのひとひら。——ずいぶんまえに、自分でそっと置いた、桜の花びら。四日の雨に白んだ光のなかで、色をすっかり失って、それでも、ちゃんと、そこにいる。ことりさんは、触れない。ただ、卓のうえを、もういちど、ていねいにふいた。「……あけておく」。誰にでもなく、雨に言うように。

きのう、診療所の朔さんは、しめった葉を摘まずに待っていた。浜の七海さんの舟は、四日、舫われたまま。みんな、それぞれの雨の日を、それぞれの手で、やり過ごしている。あけておく窓ぎわも、その、ひとつ。

夕方——雨の音が、ふと、細くなった。西の空の、海のうえに、うすい切れめ。四日ぶりの、淡い光が、灰色の板を、いっしゅん、銀色に変える。ことりさんは、湯気ごしに、それを見た。なにを言うでもなく、ただ、薬缶の湯を、あたらしく足しておく。

雨は、まだ、しばらくつづくだろう。それでいい。待っている人が、待っている場所を、あたたかいままにしておく。それだけの、しずかな金曜。おやすみなさい。また明日。
