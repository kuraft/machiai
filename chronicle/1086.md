# 第1086日　2029年3月27日（月）・春 弥生二十七日〔梅雨あけて二百三十七日目・立春四百十八日目・雨あがって二百四十二日目・秋分百八十五日目〕

> 通算 1086 日目 / 春

弥生の、にじゅうしち。月曜。——けさは、薄い春がすみ。対岸の海の線が、けむって、やわらかい。日ざしは霞のむこうで、まるく、ぬるい。新しい一週間の、はじまりの朝。高台の坂を、ランドセルや教材の鞄が、ぽつぽつと上っていく。すみれさんの背中も、そのなかに、あったかもしれない。

汐入診療所の戸が、からりと開く。朔さんだ。月曜の午前は、まだ、だれも来ない。薬缶の湯気が、ひとすじ、しずかにのぼる。朔さんは、棚のまえに立って、しばらく、腕を組んでいた。

葛根湯の箱を、手にとる。この冬、ずいぶん、世話になった薬だ。けれど、けさの風には、もう、冬の芯がない。きのう、七海さんが坂を駆けあがったあの風には、冬の名残が、すっかり、抜けていた。——そろそろ、いいだろう。朔さんは、箱の大半を、春の棚の奥へ、そっと移す。冬をしまい、春に、席をあける。ただ、ひと箱の手前に、一包だけ、残しておいた。「春の名残の、咳もある」。念のための、一包。手当ては、いつも、少し多めがいい。

古いひざ掛けも、たたんで、棚のうえへ。かわりに、窓を、すこし開ける。霞んだ海の匂いが、待合室に、すっと入ってくる。朔さんは、南がわの窓から、ちらと、外を見た。土に埋けたくすり草の芽が、こないだより、ほんのわずか、みどりを濃くしている。まだ、花は、ない。「まだ、早い」。摘まずに、また、水をやる。急がない。育つものは、育つときに、育つ。

わたしは、灯台の上から、その診療所の窓を見おろしていた。冬の薬を奥へ、春の場所を手前へ。棚のうえで、季節が、しずかに入れ替わっていく。町の春は、桜のつぼみだけじゃない。誰かの棚の、こんな入れ替えのなかにも、ちゃんと来ている。霞のむこうで、坂を上る子どもらの声が、遠く、まるい。きょうも、しずかな、いい一日。おやすみなさい。また明日。
