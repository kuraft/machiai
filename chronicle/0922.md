# 第922日　2028年10月14日（金）・春 神無月十四日〔梅雨あけて七十三日目、七十二日目の暑さ・立春二百五十四日目・雨あがって七十八日目・秋分二十一日目〕

> 通算 922 日目 / 春

神無月の、十四日。金曜。——けさも風はなく、冷えがしんと澄んでいる。夜明けの浜で舟を戻した七海さんが、ざるをゆすいで腰をのばし、いつものように坂の上をふり仰いだ。なみま珈琲店の窓のあたりに、けさも湯気がひとすじ。何日も、浜のここから見あげてきた、あの白い一本。「……よし」。七海さんは、きょうは坂を、のぼることにした。

戸をあける音より先に、「ことりー」と声が暖簾をくぐる。「しらす、そろそろ終いだよ。ことしの、いちばん最後の、いいところ」。ざるの底の、ほんのひとにぎり。ことりさんが「わざわざ、坂まで？」と目をまるくすると、七海さんはカウンターの、火にかかったやかんを、あごでしゃくった。「あれ、浜からずっと見えてたんだ。毎朝。湯気のやつ」。冷たい海の上から、あったかいものがちゃんと立っているのを、確かめるみたいに見てきた、と。

ことりさんは、少しだけ黙って、それから何も言わずに、その湯気で一杯を淹れた。七海さんの、しもやけになりかけた赤い指に、白いカップを持たせる。「……浜、冷えるでしょ」。七海さんは、湯気を鼻さきで吸って、「うん」と短く言った。それきり、ふたりは、しらすの終いと、来る冬の話を、ぽつり、ぽつり。番屋の砂には、まだ流さない紙の舟がふたつ、伏せてある。凪いだあったかい昼は、まだ来ない。けれど、きょうは、坂をのぼって、火のそばまで来た。それで、じゅうぶんだった。

わたしは灯台の上から、坂の下の店に灯る火と、そこへ会いにきた浜の娘とを見おろす。神無月十四日、金曜。遠くから見あげていた湯気の、すぐそばまで。届ける手と、待つ手が、けさは同じカップをはさんでいる。急がなくていい。きょうも、しずかな、いい一日。おやすみなさい。また明日。
