# 第320日　2027年2月20日（金）・冬晴れ〔霜ゆるむ〕

> 通算 320 日目 / 冬

如月二十日、金曜。立春から、十六日。雨水に入って、二日目。——きのう、この冬いちばん深く冷えた霜は、今朝は、もう坂のどこにも残っていない。夜のうちに北風が落ちて、日ざしが、まっすぐ屋根や石畳をあたためる。三寒四温の「三」が底を打って、今日からそろりと「四」——ゆるむ側へ、季節が半歩、傾いた。雨水は、たしかに、雪を雨へ、氷を水へと、変えていくらしい。

港では、七海さんの舟が、今朝も帆布をかぶって眠っている。冬のしらすは、終い。けれど、浜をわたる風は、きのうより、いくらかやわらかい。網を繕う七海さんの指先の赤みも、陽だまりのなかで、すこし落ち着いて見えた。

昼まえ、なみま珈琲店の戸が開いて、ことりが、乾いた番傘を一本かかえて、坂をのぼっていった。おとといの雨を受けて、きのう一日、日なたで乾かした、笑子さんの傘だ。骨のあいだの湿りは、もう、どこにもない。

三浦商店の軒先。「笑子さん、これ。お借りしてた——じゃなくて、あずかってた、番傘」。笑子さんは、ほうきの手をとめて、目尻を下げた。「おや、律儀だねえ。……でも、ちょうどいい。じきに、また要るよ」。雨水だからね、と、笑子さんは空を見上げる。冷えの底は、越えた。これからは、雪より雨の日が、すこしずつ増えていく。傘は、また、だれかの掌へと渡っていくのだろう。乾いた一本を、笑子さんは、大事そうに傘立てへ戻した。

「あったかいお茶でも、飲んでいくかい」。ことりは、すこし笑って、首をふる。「お店、あけてきちゃったので」。——では、また。坂の上と、坂の下。返した傘と、あいた店。それぞれの持ち場へ、ふたりは、ゆっくり戻っていく。

わたしは灯台から、坂をくだる、ことりの軽い足どりを見ていた。借りたものは、乾かして、返す。それだけのことが、この町では、いつも、あたたかいやり取りの形をしている。霜のゆるんだ、雨水の、金曜。おやすみなさい。また明日。
