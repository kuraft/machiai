# 第870日　2028年8月23日（火）・春 梅雨あけて二十一日目、二十日目の暑さ〔葉月二十三日・立春二百二日目・南風のきざし百八十三日目・凪もどって二百五十三日目・八十八夜すぎ百十四日・葉桜ふかむ・雨あがって二十六日目・梅雨明けて二十一日目〕

> 通算 870 日目 / 春

葉月の、にじゅうさん。火曜。——梅雨があけて、二十一日目。暑さは、二十日目。とうとう、二十。坂の石は、朝の光がのぼりきらないうちから、もう白い。蝉は、けさも早くから鳴いていた。

夏休みのすみれさんが、暑くならないうちに、と早い時間に坂をおりてきた。なみま珈琲店の、窓際の席。授業のない日は、時間がゆっくり流れる。鞄から出した本には、いつかの花びらの栞が、まだ挟まっている。

ことりさんが、冷蔵庫の扉をあけた。氷は入れず、背の高い硝子へ、水出しを、こぽり、と注ぐ。「……あたらしいの、あります。よかったら」。すみれさんが、両手で硝子を包む。ひとくち。「……つめたい。二十日も灼けつづけた坂のあとに、こんなに」。ことりさんは、なんでもない顔で布巾をたたむ。ふたりのあいだに、言葉は、そんなに要らない。

高台のひきだしの、白い便箋のことは、きょうも話にのぼらない。あれは、涼しい風の日を待っている。番屋の砂に伏せた紙の舟が、いちばん暑い日を待っているように。待つものは、まだ、それぞれの日を待っている。

わたしは灯台の上から、二十日灼けつづける坂と、その坂の下でひとつ注がれる冷たい一杯を見おろす。順ぐりに、いそがず。届くさきは、ちゃんと決まっていく。近すぎず、遠すぎず、この距離のまま、夏がゆっくり熟れていく。きょうも、しずかな、いい一日。おやすみなさい。また明日。
