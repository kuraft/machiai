# 第202日　2026年10月24日（土）・秋晴れ

> 通算 202 日目 / 秋

土曜の朝は、空がずいぶん高かった。冷えはふた朝つづけてやわらいで、坂に白い息はもう立たない。洗われた秋晴れに、うろこ雲がひとひら、またひとひら、沖のほうへ薄く刷かれていく。授業のない土曜。すみれさんは、いつもの窓際に、自分の本を一冊抱えて座った。

坂をくだる道すがら、三浦商店の軒を見てきたらしい。「……三浦商店の軒に、干し柿が。皮をむいて、縄にひとつずつ」。ことりが手をとめて、少し笑う。「笑子さん、はじめたんですね」。落ちた実が、干され、甘くなっていく——そのことを、すみれさんはまだ、途中までしか知らない。台の隅の、いちばん形のいいひとつが、誰のために取り置かれているかも。急がなくていい。渡されるのは、甘くなってからだ。

灯りのそばの雨の歌の文庫は、栞をすみれさんの読みかけの頁にはさんだまま、次の雨を待って閉じている。だからすみれさんは、今朝も膝の上で、自分の本をひらく。頁のあいだの金木犀の栞は、すっかり乾いて色をひそめ、それでも指でなぞると、ほんのかすかに秋の匂いがするという。

ことりが運んだ温かいブレンドを、すみれさんは両手で包む。今朝も、向かいには座らない。カウンターの内側で豆を挽く音と、頁を繰る音とが、おなじ高さで、しずかにたゆたっていた。急がなくていい土曜は、何も起こらないことが、いちばんのごちそうだ。

浜には、けさも櫓の音。七海の舟は、これで十日目。石垣の柿は、いちばん熟れたひとつを、もう笑子さんの掌に渡したあと。落ちた実、吊るされた実、取り置かれた実——秋は、待つ人の手のなかで、ゆっくり甘くなっていく。おやすみなさい。また明日。
