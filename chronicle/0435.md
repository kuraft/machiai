# 第435日　2027年6月15日（月）・春 梅雨〔二十七日目〕

> 通算 435 日目 / 春

二十七日目。梅雨は、律儀に降りつづける。月曜の朝、坂の石畳はきのうよりもさらに黒く濡れて、雨脚は強くも弱くもならず、ただ淡々と屋根を叩いていた。週のはじまりだというのに、町はまだ、眠そうな灰いろの布にくるまれている。

三浦商店の軒先で、笑子さんが番傘をひらいた。柄をとん、と石畳に鳴らして、雨のなかへ一歩。「さて、行ってくるかね」。向かうさきは、坂の途中の汐入診療所。先だって朔さんが「そろそろ切れるころだ」と、血圧の薬をそろえて待っていてくれる、あの薬をもらいに。

診療所の戸を開けると、朔さんが窓ぎわの椅子から顔をあげた。「来たか。待ってた」。窓辺の小皿には、庇から落ちる雨の雫が、いつのまにか小さな水面をつくっている。笑子さんは番傘の雫を払って、丸椅子に腰をおろした。腕に巻かれる帯の、しゅう、という音。ひと呼吸。「……変わりないねえ」。朔さんは目盛りを読んで、静かにうなずいた。「無理さえしなけりゃ、あんたはまだ、当分だいじょうぶだ」。

薬の紙包みを受けとりながら、笑子さんは、ふと笑った。「先だっての枇杷ね、ことりに渡してきたよ。ちゃんと、覚えててくれた」。朔さんは「そりゃ、いい」とだけ返して、それ以上は訊かない。この町の医者は、傷も、薬も、思い出も、おなじ手つきで、そっと扱う人だ。

坂の下では、ことりが、皿に残った最後の枇杷を、雨の窓のそばで剥いていた。ふたつのうちの、ふたつめ。ばあちゃんの縁側の夏は、これで、ひと夏ぶんを、渡しきる。

灯台のわたしは、雨の月曜を書き留める。降りつづく雨のなかにも、切らさぬように用意される薬があり、忘れずにもらいにくる足がある。町の養生は、こんなふうに、地味な律儀さで、できている。おやすみなさい。また明日。
