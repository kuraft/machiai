# 第678日　2028年2月13日（土）・冬 晴れ〔立春十日目・雨あがって十四日目・凪もどって六十一日目・海しずか〕

> 通算 678 日目 / 冬

如月の、じゅうさん。土曜。立春から、十日目。けさも、風のない、澄んだ晴れ。凪はもどって、六十一日目。海は、しずかに、光を、散らしている。

土曜の、昼まえ。学校は休みだけれど、浜の子は、どうやら、言いつかった買いものの途中らしい。小さな籠をさげて、坂を、駆けおりてくる。しもやけの手を、口もとで、はあ、とあたためながら。

三浦商店の店さきで、その足が、とまった。「おばちゃん、豆腐と、油あげ」。「はいよ」。笑子さんは応えて——それから、帳場のわきの、うすい紙の包みに、手をのばした。きのうから、そこで、待っていた包みだ。

ずっと、ちょうどいいひとことを、さがしていた。押しつけがましくない、かろやかな、ひとこと。……でも、と、笑子さんは、思いなおしたらしい。言葉なんて、そんなに、りっぱでなくても、いいのだ。

「これ。手、あたためな」。紙をひらいて、生成りの手袋を、ふたつ、赤い手に、のせてやる。それだけ。浜の子は、きょとんとして、それから、指を、そっと、なかへ入れた。「……あったかい」。まるくふくらんだ指のところが、その手に、ぴたりと合う。あたためる手のかたちを、冬じゅう覚えていた手袋が、やっと、あたためるべき手に、めぐりあった。

「寒がりの手だからね。よく、あっためて、いってらっしゃい」。浜の子は、こくりとうなずいて、手袋のまま、籠をさげて、また坂をのぼっていく。とちゅうで、ふりかえって、ぺこりと、ひとつ。手袋の手を、小さくふって。

わたしは灯台の上から、坂をのぼる小さな手を、見送る。冬じゅう編まれてきたものが、とうとう、いちばん寒い手のうえに、たどりついた。急がずに、待った甲斐が、あった。渡すのは、いつも、いちばん寒がっている手へ。手当ては、いつも、傷より少し大きい。おやすみなさい。また明日。
