# 第507日　2027年8月26日（水）・春 梅雨〔九十九日目・もどり雨〔霧雨〕〕

> 通算 507 日目 / 春

九十九日目。葉月の二十六日、水曜。霧雨は、まだ細い糸のまま降っている。あと一日で、この雨も、百日になる。

昼の授業を終えた白石すみれさんが、傘をかたむけて坂を下りてくる。校門の紫陽花は、九十九日ぶんの雨を吸って、青を藍のちかくまで深めていた。長い湿りのせいだろうか、すみれさんの喉は、朝から少し掠れている。

診療所の前を通りかかると、高梨朔さんが、ちょうど昼の札を戸口に返すところだった。「……先生」。すみれさんが会釈をすると、朔さんは、そのひとことの掠れに、すぐ気づいたらしい。老眼鏡ごしに、ちらりと。「湿気に、やられたな。ちょっと待て」。奥へ引っこんで、戻ってきた手のひらには、蓋を半分ゆるめた、はっか飴の缶。「一粒、どうだ。薬じゃないが、喉が楽になる」。

すみれさんが遠慮がちに一粒つまむと、霧雨のなかに、すっと薄荷の匂いが立った。「……ありがとうございます」。朔さんは坂の上を、一度だけ見上げる。「あと一日で、百日か。長いもんだ」。「はい。……でも、校門の紫陽花が、いちばんきれいな青になりました」。「そうか」。朔さんは、それ以上は言わない。ただ、缶の蓋は、いつも半分ゆるめてある。喉が掠れてから慌てるより、その前に。降りはじめる前に、できることを、ひとつずつ。

すみれさんは、薄荷を口にふくんだまま、また霧の坂を下りていく。鞄のなかには、まだ渡していない一冊。坂の下には、いちばん明るい窓際を、毎朝拭いてくれる人がいる。

灯台のわたしは、九十九日目の霧雨と、蓋を半分ゆるめた缶と、藍のちかくまで来た紫陽花の青を、書き留める。手当てというのは、いつも、痛みよりほんの少し早い。あと一日で、百日。おやすみなさい。また明日。
