# 第938日　2028年10月30日（日）・春 神無月三十日〔梅雨あけて八十九日目・立春二百七十日目・雨あがって九十四日目・秋分三十七日目〕

> 通算 938 日目 / 春

神無月の、三十日。日曜。——きのう昼すぎに、そろりと戻ってきた冷えが、けさは、もう一段ふかい。風がとがって、海の色が硬い。それでも、まだ、身の芯まで凍える朝ではない。ちょうど、そのすこし手前。

日曜は、診療所の休みの日。高梨朔さんは、いつものように、浜を歩いていた。潮の匂いが、いつもより冷たくすんでいる。砂を踏む音が、乾いて響く。朔さんは、指のさきを外套のポケットに深くしまいながら、これから来る冬の、いちばん冷える朝のことを、すこし考えていた。——そういう朝は、決まって、誰かの手が荒れる。

帰りみち、坂の下のなみま珈琲店に、灯りがともっているのが見えた。日曜でも、ことりさんの店はあいている。朔さんは、戸を押した。あたたかい空気と、豆の香りが、頬にあたる。「……あいかわらず、いい匂いだな」。ことりさんは湯を落としながら、ちいさく笑って「先生、浜、寒かったでしょう」と一杯をいれた。

朔さんは、両手でカップを包む。じんわりと、指のさきに熱がもどっていく。——きのう、すみれさんが窓ぎわでそうしたように。おとといは、七海さんが。冷えた手をあたためる一杯が、この店で、日ごとにだれかの手に渡っている。朔さんはそれを知らないけれど、おなじ湯気が、おなじようにだれかをあたためている。

わたしは灯台の上から、硬い海と、あたたかい窓を見おろす。神無月三十日、日曜。冷えは、また一段ふかくなった。三浦商店の膝の上のものが、待っている朝が、すこしずつ近づいてくる。けれど、まだ。急がなくていい。きょうも、しずかな、いい一日。おやすみなさい。また明日。
